# TechNova Academy

A complete professional IT training institute website built strictly with:

- HTML5
- CSS3
- Vanilla JavaScript

## No framework / package

There is intentionally:
- no React
- no Vue / Angular / Svelte
- no Tailwind / Bootstrap / jQuery
- no Node / Express / PHP / Python backend
- no TypeScript
- no npm
- no Vite / Webpack
- no package.json
- no node_modules

## Open directly

Double-click `index.html` and open it in Google Chrome.

Pages:
- index.html
- courses.html
- placements.html
- about.html
- contact.html

## Features

- Sticky responsive navbar
- Animated mobile menu
- Scroll reveal
- Animated statistics using IntersectionObserver
- Course search + category filtering
- Placement filtering
- Testimonial slider + autoplay + pause on hover
- FAQ accordion with `aria-expanded`
- Demo/contact form validation
- Success notifications
- Back-to-top button
- Responsive layouts
- CSS-only hero illustration
- Semantic HTML
- SEO metadata on every page
- No external image dependency

## Content note

The site is an original TechNova Academy concept inspired by the requested information architecture. Placement records, statistics, contact information and addresses are demo content and should be replaced with verified information before production use.
